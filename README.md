## Features

- **Responsive Design:** Works seamlessly on desktop and mobile devices.
- **Sidebar Navigation:** Quick access to About, Resume, Portfolio, and Contact sections.
- **Skills & Experience:** Detailed breakdown of technical skills and professional background.
- **Project Portfolio:** Interactive gallery of web projects with live previews.
- **Contact Form:** Users can send messages directly from the site.
- **Downloadable Resume:** PDF resume available for download and view.
- **Custom Animations:** Enhanced with GSAP and CSS animations.
- **Rich Media:** Includes images, icons, and sound effects for an engaging experience.

## How to Use

1. **Clone or Download the Repository:**
   ```
   git clone <repo-url>
   ```
2. **Open the Portfolio:**
   - Open `index.html` in your web browser.
3. **Browse Projects:**
   - Navigate to the Portfolio section and click "View Project" to explore individual demos.
4. **Download Resume:**
   - Go to the Resume section and click "Download Resume" for the PDF.

## What I Learned
Building this portfolio website helped me grow as a developer in several ways:

- **Responsive Web Design:** Gained hands-on experience in creating layouts that adapt to different devices and screen sizes using CSS and media queries.
- **Component-Based Thinking:** Learned to break down the UI into reusable components, making the codebase more organized and maintainable.
- **JavaScript Interactivity:** Improved my skills in DOM manipulation, event handling, and integrating third-party libraries (like GSAP for animations).
- **API Integration:** Practiced fetching and displaying real-time data (e.g., weather app) using JavaScript and public APIs.
- **Project Structuring:** Understood the importance of organizing assets (CSS, JS, images, sounds) for scalability and clarity.
- **Cross-Browser Compatibility:** Ensured the site works smoothly across different browsers and platforms.
- **UI/UX Principles:** Focused on user-centric design, accessibility, and smooth navigation for a better user experience.
- **Version Control:** Strengthened my workflow with Git for tracking changes and collaborating.
- **Personal Branding:** Learned how to present my skills, experience, and projects effectively to potential employers or collaborators.

This project was a valuable opportunity to apply and deepen my frontend development skills while building something I'm proud to share.
